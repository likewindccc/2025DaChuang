## 1. 启动入口

标准入口是创建 `SMMCalibrator` 并调用 `calibrate()`：

```python
from MODULES.CALIBRATION import SMMCalibrator

calibrator = SMMCalibrator("CONFIG/calibration_config.yaml")
result = calibrator.calibrate()
```

---

## 2. 标准运行顺序（当前实现）

### Step A：初始化阶段（`__init__`）

1. 读取 `CONFIG/calibration_config.yaml`。
2. 加载目标矩文件 `CONFIG/target_moments.yaml`（M1-M8）。
3. 根据 `weight_type` 构建初始权重矩阵。
4. 初始化参数工具（边界、初值、配置映射路径）。
5. 初始化checkpoint配置、输出目录、两阶段配置。

### Step B：校准入口检查（`calibrate` 开始）

1. 若 `checkpoint.auto_resume=true` 且存在最新断点，则自动走 `resume_from_checkpoint`。
2. 打印参数信息与目标矩信息。
3. 确定优化方法（默认 differential evolution）。
4. 组装完整初始参数向量并裁剪到边界。
5. 创建“完整参数MFG求解器”包装函数。

### Step C：Step0 Jacobian敏感性分析（可开关）

1. 对每个参数做正负微扰（基于边界跨度与 `relative_step`）。
2. 每次微扰都运行完整MFG求解，获取模拟矩向量。
3. 用中心差分计算 Jacobian 与弹性指标。
4. 输出：
   - `OUTPUT/calibration/jacobian_analysis.csv`
   - `OUTPUT/calibration/jacobian_matrix.npy`
   - `OUTPUT/calibration/jacobian_elasticity.npy`

### Step D：Step1 参数分类（可开关）

1. 按 `max_abs_elasticity` 与阈值分类为 `internal/external`。
2. 支持 `external_params_override` / `internal_params_override` 人工覆盖。
3. 输出 `OUTPUT/calibration/parameter_partition.yaml`。
4. 将 external 参数固定为当前值，internal 参数组成优化向量。

### Step E：Step4 鲁棒阶段优化

1. 按 stage4 权重类型构建权重矩阵（默认 bootstrap 逆方差）。
2. 创建 `ObjectiveFunction` 并进入优化器（DE 或其他 scipy 方法）。
3. 每次目标函数评估流程：
   - internal 参数扩展为 full 参数；
   - 写临时 MFG 配置并求解均衡；
   - 计算模拟矩与目标矩差；
   - 计算 \(J(\theta)=\Delta m' W \Delta m\)；
   - 记录历史与必要时保存checkpoint。

### Step F：Step5 高效阶段优化（可开关）

1. 用 Step4 最优点重复求解若干次，估计矩差分协方差矩阵。
2. 构造 `efficient_from_covariance` 权重（协方差逆，含正则）。
3. 以 Step4 结果为起点再次优化。
4. 输出：
   - `OUTPUT/calibration/moment_covariance_stage5.csv`
   - `OUTPUT/calibration/moment_diff_draws_stage5.csv`

### Step G：收尾与落盘

1. internal 最优解扩展为 full 参数解。
2. 生成阶段摘要 `calibration_stage_summary.yaml`。
3. 保存 `calibrated_parameters.yaml` 与 `optimization_result.pkl`。
4. 备份并回写 `CONFIG/mfg_config.yaml` 为校准后参数。

---

## 3. 关键配置开关

- `calibration_strategy.step0_jacobian.enabled`：是否执行Step0。
- `calibration_strategy.step1_classification.enabled`：是否执行Step1。
- `two_stage_calibration.enabled`：是否启用两阶段（Step4+Step5）。
- `two_stage_calibration.stage5.enabled`：是否执行Step5。
- `checkpoint.enabled`：是否保存断点。
- `checkpoint.auto_resume`：是否自动从最新断点恢复。

---

## 4. 当前默认配置（2026-03-03）

1. **Step0 默认关闭**：`step0_jacobian.enabled=false`，使用已有 elbow 结果避免重复高成本计算。
2. **Step1 使用 override**：
   - external: `gamma_S`, `kappa`, `alpha_T`
   - internal: `gamma_W`, `gamma_T`, `gamma_D`, `rho`
3. **权重策略**：
   - Step4: `inverse_variance_bootstrap`
   - Step5: `efficient_from_covariance`
4. **断点恢复默认开启**：`checkpoint.auto_resume=true`。

## 6. 正式完成判据（建议作为执行检查清单）

完成一次“正式4维SMM校准运行”建议至少满足：

1. 输出目录存在 `calibrated_parameters.yaml` 与 `optimization_result.pkl`。
2. `calibration_stage_summary.yaml` 显示非测试桩的真实评估次数（`nfev` 显著大于1）。
3. `CONFIG/mfg_config.yaml` 已按最终参数回写，且有对应备份文件。
4. 同步更新结果说明文档（参数值、目标矩拟合误差、关键诊断图）。
