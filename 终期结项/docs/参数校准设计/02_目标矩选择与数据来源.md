## 2. 目标矩选择的理论原则

### 2.1 核心原则

根据结构估计文献（Andrews, Gentzkow & Shapiro, 2017; DeBacker, 2016），目标矩的选择应遵循以下原则：

1. **阶条件**：矩的数量 $k$ 必须大于等于参数数量 $p$
2. **识别相关性**：每个待估参数至少有一个对其高度敏感的矩
3. **数据可获得性**：矩必须能从可靠的经验数据中计算
4. **模型可计算性**：矩必须能从模型模拟结果中计算
5. **矩的独立性**：避免高度相关的矩（降低权重矩阵的条件数）

### 2.2 参数-矩对应关系（理论预期）

基于模型结构的先验分析，各参数与可能的目标矩之间的理论对应关系如下：

| 参数 | 经济含义 | 主要影响的模型输出 | 对应的目标矩 |
| --- | --- | --- | --- |
| $\rho$ | 贴现率 | 所有前瞻性决策（弱影响） | 不易识别，建议外部校准 |
| $\kappa$ | 努力成本 | 个体最优努力水平 → 就业概率 | 失业率、就业转移率 |
| $\alpha_T$ | 工时负效用 | 工时偏离的惩罚 → 工时分布 | 平均工时、工时标准差 |
| $\gamma_T$ | T更新速率 | 工时状态的持续性 | 工时自相关（面板矩） |
| $\gamma_S$ | S更新速率 | 技能积累速度 → 工资增长 | 工资分散度、工龄-工资梯度 |
| $\gamma_D$ | D更新速率 | 数字素养演化 → 技术岗位匹配 | 数字经济就业比例（如有） |
| $\gamma_W$ | W更新速率 | 期望工资调整 → 工资分布 | 平均工资、工资标准差 |

注：上表为理论先验。当前项目基于已产出的 Jacobian 弹性排序，`rho` 被划入内部优化集合（见 `calibration_config.yaml` 的 Step1 override）。

## 3. 推荐的目标矩体系

### 3.1 分层设计

将目标矩分为三个层次，按优先级逐步纳入：

#### 第一层：核心矩（必选，6个）

这些矩对参数识别至关重要，且数据来源可靠：

| 编号 | 矩名称 | 符号 | 含义 | 主要识别的参数 |
| --- | --- | --- | --- | --- |
| M1 | unemployment_rate | $u$ | 均衡失业率 | $\kappa$ |
| M2 | mean_wage | $\bar{w}$ | 就业者平均月工资 | $\gamma_W$ |
| M3 | std_wage | $\sigma_w$ | 工资标准差 | $\gamma_W$, $\gamma_S$ |
| M4 | mean_weekly_hours | $\bar{T}$ | 就业者平均每周工时 | $\alpha_T$, $\gamma_T$ |
| M5 | job_finding_rate | $f$ | 失业→就业月转移概率 | $\kappa$ |
| M6 | separation_rate | $s$ | 就业→失业月转移概率 | 分离率参数（$\eta$ 系列） |

#### 第二层：辅助矩（推荐，用于过度识别，2-3个）

| 编号 | 矩名称 | 符号 | 含义 | 主要识别的参数 |
| --- | --- | --- | --- | --- |
| M7 | wage_iqr_ratio | $w_{75}/w_{25}$ | 工资75/25分位数比值 | $\gamma_S$, $\gamma_W$ |
| M8 | std_weekly_hours | $\sigma_T$ | 每周工时标准差 | $\gamma_T$ |
| M9 | digital_job_ratio | $d_{job}$ | 数字技能岗位占比（工作中经常/有时使用互联网） | $\gamma_D$（辅助） |

#### 第三层：扩展矩（可选，用于稳健性检验）

| 编号 | 矩名称 | 含义 | 说明 |
| --- | --- | --- | --- |
| M10 | unemployment_duration | 平均失业持续时间 | 与job_finding_rate互为倒数关系 |
| M11 | wage_gini | 工资基尼系数 | 综合衡量工资不平等 |
| M12 | labor_force_participation | 劳动力参与率 | 特别是农村女性的参与率 |

### 3.2 最终推荐方案

**目标矩基线方案**：6个核心矩（M1-M6）+ 2个辅助矩（M7-M8）= **8个矩**。

当前项目实现采用“3外部固定 + 4内部优化”：
- 外部固定：`kappa`, `alpha_T`, `gamma_S`
- 内部优化：`gamma_W`, `gamma_T`, `gamma_D`, `rho`

因此当前执行口径下是 **8个矩 vs 4个参数**（过度识别）。  
后续如切换参数分类策略（例如将更多参数转为内部优化），仍可沿用本目标矩体系并保持可识别性。

## 4. 各矩的数据来源与目标值

### 4.1 数据来源优先级

```text
首选：CLDS（中国劳动力动态调查） → 筛选农村女性子样本
次选：CFPS（中国家庭追踪调查）  → 作为交叉验证
宏观：国家统计局 / 统计年鉴     → 宏观矩的权威来源
补充：CHIP（中国家庭收入调查）   → 工资分布相关矩
```

### 4.2 各矩目标值与来源

#### M1: unemployment_rate（失业率）

| 项目 | 说明 |
| --- | --- |
| 定义 | 失业人口 / 劳动力人口 |
| 推荐目标值 | **1.5% - 2.5%**（CLDS实算中心值约1.73%） |
| 来源 | CLDS 2018 农村女性子样本（ILO三分法） |
| 置信区间 | [1.0%, 3.0%] |
| 备注 | 与城镇统计口径存在显著差异，应优先采用研究对象一致的CLDS子样本口径 |

#### M2: mean_wage（平均月工资）

| 项目 | 说明 |
| --- | --- |
| 定义 | 就业者月工资收入的算术平均 |
| 推荐目标值 | **3200 - 4000元/月**（本次实算3578元/月） |
| 来源 | CLDS 2018 农村女性在业样本（I3a_6/12） |
| 备注 | 研究对象为农村女性，显著低于全国农民工总体均值属正常现象 |

#### M3: std_wage（工资标准差）

| 项目 | 说明 |
| --- | --- |
| 定义 | 就业者月工资的标准差 |
| 推荐目标值 | **2200 - 3000元/月**（本次实算2592元/月） |
| 来源 | CLDS 2018 农村女性在业样本计算 |
| 备注 | 可用变异系数（CV = std/mean）作为替代指标，消除量纲影响 |

#### M4: mean_weekly_hours（平均每周工时）

| 项目 | 说明 |
| --- | --- |
| 定义 | 就业者每周实际工作小时数的平均值 |
| 推荐目标值 | 40 - 50小时/周 |
| 来源 | CLDS工作模块；国家统计局（2023年全国企业就业人员周均工作时间约48.7小时） |
| 备注 | 农村非正规就业工时可能波动较大 |

#### M5: job_finding_rate（就业转移率）

| 项目 | 说明 |
| --- | --- |
| 定义 | 失业个体在单位时间内找到工作的概率（月度） |
| 推荐目标值 | **0.02 - 0.04/月**（本次实算0.0285/月） |
| 来源 | CLDS 2016-2018面板：2016 `I3a_7_0`（当前状态）→ 2018 `I3_1`（工作经历）折算月度 |
| 计算方法 | 若两波间隔为24个月，年转移率为 $F$，则月转移率 $f = 1-(1-F)^{1/24}$ |
| 备注 | 当前分母样本较小（n=12），仅作低置信度约束；建议后续补充波次或替代定义做稳健性检验 |

#### M6: separation_rate（分离率）

| 项目 | 说明 |
| --- | --- |
| 定义 | 就业个体在单位时间内失去工作的概率（月度） |
| 推荐目标值 | **0.002 - 0.006/月**（本次实算0.0028/月） |
| 来源 | CLDS 2016-2018面板，计算方式同M5 |
| 备注 | 农村就业稳定性高，分离率显著低于城镇文献值；当前分母样本n=108，置信度高于M5 |

#### M7: wage_iqr_ratio（工资四分位距比）

| 项目 | 说明 |
| --- | --- |
| 定义 | 工资75分位数与25分位数的比值 $w_{75}/w_{25}$ |
| 推荐目标值 | **2.5 - 3.5**（本次实算3.00） |
| 来源 | CLDS/CHIP农村女性子样本 |
| 备注 | 比标准差更稳健地刻画工资分散度，对异常值不敏感 |

#### M8: std_weekly_hours（每周工时标准差）

| 项目 | 说明 |
| --- | --- |
| 定义 | 就业者每周工时的标准差 |
| 推荐目标值 | **18 - 24小时**（本次实算21.1小时） |
| 来源 | CLDS工作模块 |
| 备注 | 主要用于识别 $\gamma_T$（工时更新速率） |

#### M9: digital_job_ratio（数字技能岗位占比，辅助矩）

| 项目 | 说明 |
| --- | --- |
| 定义 | 就业者中“工作中经常/有时使用互联网”比例 |
| 推荐目标值 | **0.50 - 0.62**（本次实算0.568） |
| 来源 | CLDS 2018 `I3a1_19_4`（1=经常，2=有时） |
| 备注 | 作为 $\gamma_D$ 的辅助识别矩；当前有效样本n=345，置信度中等 |

## 5. 从模型中计算模拟矩

### 5.1 当前实现

当前 `MODULES/CALIBRATION/target_moments.py` 的 `compute_simulated_moments` 已支持 M1-M8。
核心实现口径如下：

```python
# 就业样本提取兼容两种字段
# employment_status == "employed" 或 employed == 1

# 工资列兼容: current_wage -> W
# 工时列兼容: weekly_hours -> T

# M1: unemployment_rate
# 优先从 eq_info["final_statistics"] 读取，否则由样本就业状态回推

# M5/M6: job_finding_rate / separation_rate
# 仅从 final_statistics 指定键读取，缺失则显式报错，不做静默兜底

# M2/M3/M4/M7/M8:
# 由就业样本的工资与工时分布直接计算
```

### 5.2 关键实现细节（当前版本）

1. 动态矩读取键名支持：
   - M5：`job_finding_rate` / `job_finding_rate_expected` / `lambda_mean_unemployed`
   - M6：`separation_rate` / `separation_rate_expected` / `mu_mean_employed`
2. 失业率优先读均衡统计；若缺失再从个体状态字段回推。
3. 工资IQR比值在分母过小（P25接近0）时返回0，避免数值爆炸。
4. `bootstrap_se` 支持严格模式：`strict=True` 时若缺失标准误将直接报错。

### 5.3 关于动态矩（M5, M6）的计算

就业转移率和分离率在MFG均衡中可以从以下方式获取：

- **job_finding_rate**：均衡状态下，失业个体的平均匹配概率 $\lambda(x, a^*(x), \theta)$，对失业人口加权平均
- **separation_rate**：均衡状态下，就业个体的平均分离概率，由分离率函数 $\delta(x)$ 对就业人口加权平均

这两个矩可以直接从 `eq_info` 字典中获取，前提是MFG求解器在均衡计算过程中保存了这些信息。

## 6. 权重矩阵设计

### 6.1 当前实现方案（已接入）

当前配置采用两阶段权重：

1. Step4：`inverse_variance_bootstrap`（对角逆方差，基于 `bootstrap_se`）
2. Step5：`efficient_from_covariance`（基于矩差分协方差逆矩阵）

与早期“目标值归一化对角权重”相比，当前方案对不同矩估计精度的利用更充分。

### 6.2 仍可保留的备选方案

若后续需要快速基线测试或排查权重敏感性，可切换为：
- `identity`
- `diagonal`（手工权重）
- 目标值归一化对角权重（作为稳健性对照）
