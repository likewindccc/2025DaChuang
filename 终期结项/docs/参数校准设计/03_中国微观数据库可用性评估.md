# 中国微观数据库可用性评估

**文档版本**：1.0  
**创建日期**：2025-07-01  
**关联文档**：`02_目标矩选择与数据来源.md`

---

## 1. 评估目的

本文档评估中国主要微观调查数据库对本项目参数校准的适用性。评估维度包括：

- 调查对象是否覆盖农村女性劳动力
- 就业、工资、工时等核心变量的可用性
- 面板数据的可用性（用于计算转移概率等动态矩）
- 数据获取的便利性

---

## 2. 数据库详细评估

### 2.1 CLDS（中国劳动力动态调查）

| 维度 | 详情 |
| --- | --- |
| 主办机构 | 中山大学社会科学调查中心 |
| 调查对象 | **15-64岁**劳动年龄人口 |
| 调查波次 | 2012年基线、2014年、2016年、2018年（共4轮追踪） |
| 覆盖范围 | 全国城乡村居，个体-家庭-社区三层结构 |
| 数据获取 | 通过中国国家调查数据档案馆（cnsda.org）申请，学术用途免费 |
| 面板特性 | 两年一次追踪，可计算两期间的就业状态转移概率 |

**核心调查模块与变量**：

| 模块 | 关键变量 | 与模型的对应关系 |
| --- | --- | --- |
| 劳动参与 | 就业状态（在业/失业/非劳动力） | → unemployment_rate |
| 薪酬收入 | 月工资收入、年收入 | → mean_wage, std_wage |
| 工作时间 | 每周工作时数 | → mean_weekly_hours, std_weekly_hours |
| 职业培训 | 是否参加培训、培训类型、培训时长 | → 技能(S)相关矩的参考 |
| 职业流动 | 工作变更历史、行业转换 | → job_finding_rate, separation_rate |
| 教育 | 教育年限、教育类型 | → 分教育组就业率 |
| 技能 | 职业技能相关问题 | → S维度 |
| 劳动力迁移 | 流动人口状况 | → 控制变量 |

**对本项目的适用性评估**：

| 评估维度 | 评分(1-5) | 说明 |
| --- | --- | --- |
| 年龄覆盖 | 5 | 15-64岁，完美覆盖农村女性劳动年龄人口 |
| 就业变量 | 5 | 以劳动力为核心调查对象，就业信息最丰富 |
| 工资变量 | 4 | 有月工资收入，但部分非正规就业可能缺失 |
| 工时变量 | 4 | 有每周工时，可直接计算均值和标准差 |
| 面板特性 | 4 | 4轮追踪，可计算3对转移概率 |
| 农村女性子样本 | 4 | 可按户口+性别筛选，但样本量需确认 |
| 数据获取 | 3 | 需申请，有一定审批周期 |
| **综合评分** | **4.1** | **首选数据库** |

---

### 2.2 CFPS（中国家庭追踪调查）

| 维度 | 详情 |
| --- | --- |
| 主办机构 | 北京大学中国社会科学调查中心 |
| 调查对象 | 全年龄段家庭成员（约26000人） |
| 调查波次 | 2010、2012、2014、2016、2018、2020、2022（共7轮） |
| 覆盖范围 | 全国25个省/市/自治区 |
| 数据获取 | 通过isss.pku.edu.cn注册申请 |
| 面板特性 | 两年一次追踪，时间跨度最长（12年） |

**核心就业模块（GB模块）**：

| 变量 | 说明 |
| --- | --- |
| employ | 就业状态（过去一周是否工作>=1小时） |
| 工资性收入 | 家庭工资性收入总和，个人工资收入 |
| 工作时间 | 有相关问题但不如CLDS详细 |
| 教育 | 详细教育经历 |
| 家庭变量 | 丰富的家庭结构和经济变量 |

**对本项目的适用性评估**：

| 评估维度 | 评分(1-5) | 说明 |
| --- | --- | --- |
| 年龄覆盖 | 5 | 全年龄段，可任意筛选 |
| 就业变量 | 3 | 就业状态判断相对简单，代答问卷中可能为"无法判断" |
| 工资变量 | 4 | 有工资收入，但家庭/个人层面需区分 |
| 工时变量 | 3 | 有但不如CLDS专深 |
| 面板特性 | 5 | 7轮追踪，时间跨度12年，转移矩最丰富 |
| 农村女性子样本 | 4 | 可按户口+性别筛选 |
| 数据获取 | 4 | 注册后可较快获取 |
| **综合评分** | **4.0** | **推荐作为交叉验证数据源** |

---

### 2.3 CHARLS（中国健康与养老追踪调查）

| 维度 | 详情 |
| --- | --- |
| 主办机构 | 北京大学国家发展研究院 |
| 调查对象 | **45岁及以上**中老年人（约1.7万人） |
| 调查波次 | 2011、2013、2015、2018、2020（共5轮） |
| 覆盖范围 | 全国150个县级单位，450个村级单位 |
| 数据获取 | charls.charlsdata.com 免费注册下载 |
| 面板特性 | 2-3年一次追踪 |

**工作与退休模块（F模块）**：

| 变量 | 说明 |
| --- | --- |
| 就业状态 | 在业/失业/退出劳动力市场 |
| 工资收入 | 工资性收入 |
| 工作时间 | 每周工时 |
| 农业/非农 | 区分农业劳动与非农就业 |
| 退休信息 | 正常退休与实际退出劳动力市场 |

**对本项目的适用性评估**：

| 评估维度 | 评分(1-5) | 说明 |
| --- | --- | --- |
| 年龄覆盖 | **1** | **仅45岁以上，无法覆盖年轻农村女性** |
| 就业变量 | 3 | 有基本就业信息，但偏重健康/养老主题 |
| 工资变量 | 3 | 有工资收入 |
| 工时变量 | 3 | 有每周工时 |
| 面板特性 | 4 | 5轮追踪 |
| 农村女性子样本 | 2 | 仅中老年农村女性 |
| 数据获取 | 5 | 免费注册即可下载，最便利 |
| **综合评分** | **3.0** | **年龄限制是硬伤，仅适合补充参考** |

**重要说明**：项目文档中提到使用CHARLS数据（`DATA/raw/charls_data.csv`），但CHARLS仅覆盖45岁以上人群。如果研究对象包含年轻农村女性，CHARLS的代表性不足。建议：

- 若项目聚焦于**中老年农村女性**（45+），CHARLS可用
- 若项目覆盖**全年龄段农村女性**，应以CLDS为主

---

### 2.4 CHIP（中国家庭收入调查）

| 维度 | 详情 |
| --- | --- |
| 主办机构 | 北京师范大学中国收入分配研究院 |
| 调查波次 | 1988、1995、2002、2007、2013、2018（共6轮，间隔不等） |
| 核心内容 | 收入分配：工资性收入、经营性收入、财产性收入、转移性收入 |
| 数据获取 | 通过ciidbnu.org申请 |
| 子样本 | 城镇住户、农村住户、流动人口（2002年后） |

**对本项目的适用性评估**：

| 评估维度 | 评分(1-5) | 说明 |
| --- | --- | --- |
| 年龄覆盖 | 4 | 覆盖全年龄段 |
| 就业变量 | 2 | 以收入为核心，就业状态信息有限 |
| 工资变量 | **5** | **收入信息最详细，分解最细** |
| 工时变量 | 2 | 工时信息有限 |
| 面板特性 | **1** | **非连续面板，间隔5-7年，不适合计算年度转移概率** |
| 农村女性子样本 | 4 | 有农村住户子样本 |
| 数据获取 | 3 | 需申请 |
| **综合评分** | **3.0** | **工资分布相关矩的优质补充来源** |

---

### 2.5 国家统计局宏观数据

| 数据源 | 关键指标 | 获取方式 |
| --- | --- | --- |
| 中国统计年鉴 | 城镇调查失业率、就业人口、平均工资 | stats.gov.cn 免费查阅 |
| 国家数据平台 | 分地区/分行业统计数据 | data.stats.gov.cn 免费查询 |
| 农民工监测调查报告 | 农民工总量、月均收入、就业分布 | 年度报告公开发布 |
| 劳动力调查 | 分性别/分年龄失业率 | 季度发布 |

**对本项目的适用性评估**：

| 评估维度 | 评分(1-5) | 说明 |
| --- | --- | --- |
| 宏观矩（失业率、平均工资） | **5** | **官方权威数据，论文引用最有说服力** |
| 微观矩（分布、转移率） | 1 | 无微观个体数据 |
| 农村女性细分 | 2 | 部分有分性别/分城乡数据，但细分有限 |
| 数据获取 | 5 | 完全公开 |
| **综合评分** | **3.3** | **宏观矩的最佳来源，但无法提供微观矩** |

## 4. 推荐数据使用策略

### 4.1 主方案

```text
宏观矩（M1: unemployment_rate）
    └─ 来源：国家统计局城镇调查失业率
    └─ 辅助：CLDS农村女性子样本失业率

微观矩（M2-M4, M7-M8）
    └─ 主要来源：CLDS 农村+女性 筛选
    └─ 交叉验证：CFPS 同样条件筛选
    └─ 工资补充：CHIP 农村住户子样本

动态矩（M5-M6: 转移率）
    └─ 主要来源：CLDS 面板数据（相邻两波比较）
    └─ 交叉验证：CFPS 面板数据
```

### 4.2 备选方案（若无法获取CLDS）

若CLDS数据申请未通过，可使用以下替代策略：

- **CFPS替代CLDS**：就业和工资信息基本可用，但工时信息需补充
- **CHARLS用于45+群体**：如果项目聚焦中老年农村女性，CHARLS足够
- **统计年鉴+文献值**：宏观矩用统计年鉴，工资分布矩用已发表论文中的估计值

### 4.3 数据获取行动项

| 优先级 | 行动 | 预计周期 |
| --- | --- | --- |
| 高 | 申请CLDS数据（cnsda.org注册 → 填写申请 → 等待审批） | 1-2周 |
| 高 | 申请CFPS数据（isss.pku.edu.cn注册申请） | 1-2周 |
| 中 | 下载统计年鉴相关表格（data.stats.gov.cn） | 即时 |
| 低 | 申请CHIP数据（ciidbnu.org） | 2-4周 |
| 已有 | 确认CHARLS数据是否已获取并可用 | 即时 |
