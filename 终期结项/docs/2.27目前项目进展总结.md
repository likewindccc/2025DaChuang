## 一、项目总体概况

本项目聚焦中国农村女性就业困境，构建了一个融合**平均场博弈（MFG）**与**基于主体建模（ABM）**思想的动态演化模拟系统，刻画个体决策与宏观市场之间的相互作用，旨在通过计算机模拟方法揭示市场演化与长期均衡，探究劳动力市场运行的内在机制，进而评估政策干预效果。

项目自2025年3月立项以来，已历经**立项阶段**、**中期报告阶段**（2025年11月7日提交），当前进入**终期结项准备阶段**。

## 二、已完成工作概览

### 2.1 田野调查与数据收集

| 阶段 | 内容 | 成果 |
|------|------|------|
| **预调研**（立项前） | 线上访谈+预问卷 | 访谈5名农村女性；回收30份有效预问卷（有效率88.33%） |
| **正式调研（第一、二批）** | 大规模问卷调查+实地访谈 | 团队成员赴湖南长沙、海南海口、浙江绍兴、云南曲靖等地实地调研；回收327份问卷，经清洗后300份有效（有效率91.7%），达到立项书中N≈301的预期样本量 |
| **模拟简历投递** | Bertrand-Mullainathan方法 | 投递9份不同简历×3次，初步验证企业对工作时间和工作能力的偏好 |

**核心发现**：
- 农村女性失业原因主要为：家庭照料负担、工作技能不足、数字素养缺失
- 样本平均年龄约37岁，平均期望月收入4521元，平均工作时间期望5.22天/周、8.04小时/天
- 年龄与学历呈强负相关（-0.75），反映教育普及的代际差异
- 学历与工作能力、数字素养呈中度正相关（0.52、0.54）

#### 2.2.2 各模块完成情况

**模块1：POPULATION（人口分布）—— 100%完成**

- 基于300份真实问卷数据，使用**Gaussian Copula**理论建立4维联合分布（T工作时长, S技能水平, D数字素养, W期望工资）
- 连续变量使用核密度估计拟合边际分布，离散变量使用经验分布
- 企业分布使用4维正态分布建模（参数来自文献设定）
- 支持参数保存/加载功能

**模块2：LOGISTIC（匹配与匹配函数）—— 100%完成**

- **虚拟市场生成器**：从总体分布中抽样生成虚拟劳动力和企业
- **Gale-Shapley匹配算法**：实现双边稳定匹配，Numba加速（50-100倍提速），max_rounds=32（已调优）
- **匹配函数回归**：基于10轮×10000劳动力的模拟数据（约10万样本），通过Logistic回归得到匹配概率函数

匹配函数拟合结果：
$$P(\text{matched}=1) = \frac{1}{1 + \exp(-Z)}$$
$$Z = -5.735 + 0.129T + 0.040S + 0.128D - 0.001W - 0.162\sigma + 0.812\theta$$

- 所有系数在0.01水平下显著，Pseudo R²=0.185
- 市场紧张度θ是最强预测因子（系数0.812）
- 数字素养D和工作时长T的影响力相当（0.128 vs 0.129）
- 期望工资W呈显著负向影响

**模块3：MFG（平均场博弈）—— 85%完成**

- **Bellman方程求解器**：Numba加速值迭代（10-30倍加速，parallel=True）
- **KFE演化求解器**：基于个体的蒙特卡洛方法（N=10000个体），避免4维离散网格的维度灾难
- **均衡求解器**：交替迭代Bellman+KFE，支持阻尼更新、相对收敛阈值
- **已实现的优化**：离职率标准化（消除两极分化）、值函数修正方案、收敛判断逻辑优化
- **均衡结果**：系统经85轮迭代成功收敛至稳态均衡，最终失业率6.51%
- **当前问题**：收敛性仍有优化空间

**模块4：SIMULATOR（市场模拟器）—— 已开发**

- 支持多场景批量模拟：基准场景、低强度培训政策、高强度培训政策
- 可通过配置文件调整人口分布参数（如mean_S_multiplier、mean_D_multiplier）
- 支持结果汇总与对比分析

**模块5：CALIBRATION（参数校准）—— 已开发**

- 实现了基于**SMM（模拟矩匹配）**的参数校准框架
- 支持Nelder-Mead和**Differential Evolution并行优化**算法
- 已针对AutoDL云服务器优化并行策略（32进程并行，禁用Numba级并行以避免资源冲突）
- 使用multiprocess库解决闭包序列化问题
- 支持断点续跑、中间结果保存、诊断报告生成
- 目标矩：失业率、平均工资、匹配率等

## 三、关键技术实现细节

### 3.1 核心算法流程

```
原始问卷数据 → 数据清洗编码
    ↓
POPULATION模块：Gaussian Copula拟合劳动力4维联合分布 + 企业正态分布设定
    ↓
LOGISTIC模块：采样虚拟市场 → GS匹配(max_rounds=32) → Logistic回归 → 匹配函数λ(x,σ,θ)
    ↓
MFG模块：交替迭代{Bellman方程(值迭代) ↔ KFE(蒙特卡洛演化)} → 平均场均衡
    ↓
SIMULATOR模块：多场景政策模拟(基准/低培训/高培训) → 对比分析
    ↓
CALIBRATION模块：SMM + Differential Evolution并行优化 → 校准参数
```

### 3.2 MFG均衡求解核心结果

基于10000个异质劳动力个体的均衡求解（中期报告数据）：

| 指标 | 数值 |
|------|------|
| 收敛轮数 | 85轮 |
| 最终失业率 | 6.51% |
| 就业者平均技能水平S | 30.25（高出失业者31.3%） |
| 就业者平均数字素养D | 11.49（高出失业者41.2%） |
| 均衡努力水平 | 从初始12.1%降至2.8% |
| 人力资本积累效应 | 技能+16.1%，数字素养+24.7% |

### 3.3 关键性能优化

- **Numba JIT加速**：GS匹配50-100倍，Bellman/KFE 10-30倍
- **并行计算**：Differential Evolution 32进程并行（AutoDL），预计7-14倍加速
- **并行资源管理**：采用"进程并行+线程串行"策略，避免32×128=4096线程的过度订阅

1. **MFG收敛性**：虽然已实现收敛（85轮），但收敛性仍有优化空间，部分参数组合下可能收敛缓慢
