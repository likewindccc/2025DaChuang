# 四、参数校准

## 4.1 校准方法

本文采用模拟矩匹配法（Simulated Method of Moments, SMM）估计模型结构参数（McFadden, 1989；Pakes & Pollard, 1989）。SMM估计量定义为：

$$
\hat{\theta} = \arg\min_{\theta} \left[ m^* - m(\theta) \right]' W \left[ m^* - m(\theta) \right]
$$

其中 $m^*$ 为从调查数据计算的目标矩向量，$m(\theta)$ 为给定参数 $\theta$ 时的模型模拟矩向量，$W$ 为正定权重矩阵。

为消除不同量纲矩之间的比较困难，本文以各矩的自助法（bootstrap）标准误之倒数平方为权重，构造对角权重矩阵 $W = \mathrm{diag}(1/\hat{\sigma}_1^2, \ldots, 1/\hat{\sigma}_k^2)$，使失业率、平均工资等量纲迥异的矩在目标函数中获得与其估计精度相匹配的权重。数值优化采用差分进化算法（Differential Evolution），以应对目标函数因模型非线性而可能出现的多峰问题。

## 4.2 待校准参数与目标矩

模型包含7个需要赋值的结构参数，如表1所示。为确定哪些参数可以由数据可靠识别，本文计算了各参数对8个目标矩的数值弹性，使用中心差分法构造Jacobian矩阵，并以各参数平均绝对弹性 $\bar{\varepsilon}_j$ 为依据，按升序作拐点图。拐点由端点连线最大垂距法确定，拐点左侧的参数弹性显著偏低，表明所选矩对其识别能力有限；右侧参数则与目标矩存在稳定的识别关联。据此，$\gamma_W$、$\gamma_T$、$\gamma_D$、$\rho$ 四个参数被纳入SMM联合估计，$\kappa$ 与 $\alpha_T$、$\gamma_S$ 对所选矩的平均弹性较弱，参照已有文献进行固定取值。

**表1 待校准结构参数**

|     参数     | 含义               |   取值范围   |
| :----------: | :----------------- | :----------: |
|   $\rho$   | 贴现因子           | [0.01, 0.99] |
|  $\kappa$  | 求职努力成本系数   | [100, 10000] |
| $\alpha_T$ | 工时偏离负效用系数 |  [0.0, 1.0]  |
| $\gamma_T$ | 工时状态更新速率   | [0.01, 1.0] |
| $\gamma_S$ | 技能更新速率       | [0.01, 1.0] |
| $\gamma_D$ | 数字素养更新速率   | [0.01, 1.0] |
| $\gamma_W$ | 期望工资更新速率   | [0.01, 1.0] |

目标矩来源于中国劳动力动态调查（CLDS）2018年数据中农村女性子样本，共采用8个矩，具体目标矩定义如表2所示。

**表2 目标矩体系**

| 矩编号 | 矩名称           |  目标值  |        数据来源        |
| :----: | :--------------- | :------: | :---------------------: |
|   M1   | 失业率           |  1.73%  |  CLDS 2018，ILO三分法  |
|   M2   | 平均月工资       |  3578元  | CLDS 2018，在业女性样本 |
|   M3   | 工资标准差       |  2592元  | CLDS 2018，在业女性样本 |
|   M4   | 平均每周工时     | 48.0小时 |   CLDS 2018，工作模块   |
|   M5   | 就业转移率（月） |  0.028  | CLDS 2016-2018面板折算 |
|   M6   | 就业分离率（月） |  0.0028  | CLDS 2016-2018面板折算 |
|   M7   | 工资四分位距比   |   3.00   | CLDS 2018，在业女性样本 |
|   M8   | 每周工时标准差   | 21.1小时 |   CLDS 2018，工作模块   |

各矩与参数之间的识别对应关系如下：均衡失业率（M1）和就业转移率（M5）主要识别努力成本系数 $\kappa$；平均工资（M2）和工资四分位距比（M7）对应期望工资更新速率 $\gamma_W$；工时均值与标准差（M4、M8）识别工时更新速率 $\gamma_T$；工资标准差（M3）则同时承载 $\gamma_S$ 与 $\gamma_W$ 的联合约束；分离率（M6）直接约束就业稳定性机制。整体上，8个目标矩对4个内部参数形成过度识别，为模型的外部有效性检验提供了基础。

## 4.3 校准结果

模型全部结构参数的取值如表3所示：

**表3 参数校准结果**

|     参数     | 含义               | 取值 | 赋值方式 |
| :----------: | :----------------- | :---: | :------: |
|  $\kappa$  | 求职努力成本系数   | 1500 | 文献赋值 |
| $\alpha_T$ | 工时偏离负效用系数 | 0.250 | 文献赋值 |
| $\gamma_S$ | 技能更新速率       | 0.350 | 文献赋值 |
|   $\rho$   | 贴现因子           | 0.581 | SMM估计 |
| $\gamma_T$ | 工时状态更新速率   | 0.419 | SMM估计 |
| $\gamma_D$ | 数字素养更新速率   | 0.359 | SMM估计 |
| $\gamma_W$ | 期望工资更新速率   | 0.224 | SMM估计 |

四个内部参数的估计结果具有清晰的经济含义。贴现因子 $\rho = 0.581$ 意味着农村女性劳动者在就业决策中更侧重当期收益，这与该群体所面临的流动性约束和不确定性环境相吻合。三个状态更新速率 $\gamma_T$、$\gamma_D$、$\gamma_W$ 均处于 $[0.2, 0.5]$ 区间，表明个体的工时适应、数字技能积累和工资预期调整均具有一定惯性，其中工资预期的更新最为缓慢（$\gamma_W = 0.224$），这与行为经济学中关于参考点依赖的实证发现一致。
