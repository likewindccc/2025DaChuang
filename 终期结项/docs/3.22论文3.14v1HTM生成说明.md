# 3.14v1 HTM 生成说明

## 文件用途

本文档说明 `终期结项/论文/3.14v1_排版版.htm` 的生成方式、排版约束和可复用脚本，便于后续继续修订论文主稿时快速重新导出。

## 输入与输出

- 输入主稿：`终期结项/论文/3.14v1.md`
- 输出文件：`终期结项/论文/3.14v1_排版版.htm`
- 生成脚本：`终期结项/render_3_14v1_htm.py`

## 当前排版规则

- 所有样式均写在标签的 `style` 属性中，不使用 `<style>` 标签和外部 CSS。
- 长度单位统一使用 `pt`，以兼容复制到 Word 的场景。
- `<body>` 固定为 `margin:0;padding:0;`，避免复制后出现页面偏移。
- 一级、二级标题与正文行距统一按 28 磅控制。
- 正文按五号宋体风格输出，段首保留两字符缩进。
- Markdown 中原本以图片形式出现的前几张表格，按用户要求保留为图片原样呈现。
- Markdown 管道表统一转为三线表。
- 算法块统一转为盒式算法表，样式对齐既有 `567` 部分 HTM 的算法展示形式。
- 数学公式保留 LaTeX 文本，不做浏览器端渲染，但会额外做一层 Word 友好化清洗。
- 行间公式会自动去掉 `array` 外壳，并把公式编号从 `$$...$$` 内部移到外部。
- 会自动替换部分 Word 不易识别的写法，例如 `\text{\{}...\text{\}}`、`\lbrack`、`\text{/}`、`\#(n)` 等。

## 使用方式

在项目根目录执行：

```powershell
python .\终期结项\render_3_14v1_htm.py
```

脚本会重新读取 `3.14v1.md` 并覆盖生成最新的 `3.14v1_排版版.htm`。

## 说明

- 当前脚本按 `3.14v1.md` 的实际结构做了定制解析，覆盖标题、正文、图片、三线表、算法表、公式和注释等块类型。
- 若主稿后续新增新的 Markdown 语法结构，需要同步扩展脚本解析逻辑。
