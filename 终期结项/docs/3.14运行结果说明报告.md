## 一、总判断

这轮结果相较之前的最大进步，不在于数值本身显著变好，而在于论文表格口径已经基本统一：

- 表 4.4、表 5.2、表 6.2 的 baseline 已统一到同一组基准均衡结果。
- 表 6.3 已剔除历史残留的 `training_low/high` 场景。
- 表 7.1 已按当前论文 baseline 重新计算变化率。

但从经济结果本身看，当前版本仍然更适合作为“诊断性结果”，还不适合作为最终论文主结果。最主要的原因有三点：

1. 基准与全部政策、灵敏度场景仍未收敛。
2. 六个目标矩中，只有失业率相对接近，工资分布和工时分布矩仍明显偏离。
3. 政策效果和灵敏度方向仍存在不稳定和不完全符合理论预期的情况。

## 二、对应论文第五部分的结果说明

### 2.1 基准均衡与收敛特征

按当前论文主表口径，基准均衡的核心指标为：

- 失业率：`4.15%`
- 平均工资：`4540.95`
- 平均周工时：`46.94`
- 平均技能 `S`：`36.70`
- 平均数字素养 `D`：`19.63`

与目标矩相比：

| 指标 | 目标值 | 模拟值 | 相对偏差 |
| --- | ---: | ---: | ---: |
| 失业率 | 3.50% | 4.15% | +18.57% |
| 平均工资 | 3578.3 | 4540.95 | +26.90% |
| 对数工资标准差 | 0.649 | 0.3308 | -49.02% |
| 平均周工时 | 52.0 | 46.94 | -9.73% |
| 工资 IQR 比 | 3.0 | 1.5675 | -47.75% |
| 工时标准差 | 16.7 | 8.3315 | -50.11% |

这里最值得注意的是：

- `M1` 失业率已经比较接近目标，但仍高出 `0.65` 个百分点。
- `M2/M3/M7/M8` 仍然明显偏离，尤其工资和工时的离散度大约只有目标的一半。
- 当前模型依然存在“均值勉强靠近，但分布矩塌缩”的问题。

关于收敛性，当前不能直接写“模型已收敛”。原因是：

- 表 6.2 中 baseline 仍然是 `converged=False`。
- 场景 baseline 的最近 100 轮里，失业率标准差约 `0.00172`，工资标准差约 `5.18`，说明宏观量波动已经不算大。
- 但同一时期 `convergence_V` 平均约 `0.136`，最后一轮仍有 `0.131`，说明价值函数还没有稳定到可放心称为“完全收敛”的程度。

因此，第 5.1 节当前更合适的说法应是：

- “关键宏观量已进入相对稳定区间”
- 而不是“价值函数和策略已充分收敛”

### 2.2 就业者与失业者的特征差异

当前表 5.2 的核心结果如下：

| 指标 | 就业者 | 失业者 |
| --- | ---: | ---: |
| 样本数 | 9585 | 415 |
| 周工时 `T` | 46.94 | 47.40 |
| 技能 `S` | 36.82 | 33.94 |
| 数字素养 `D` | 19.67 | 18.59 |
| 保留工资 `W` | 4532.07 | 3898.37 |
| 当前工资 | 4540.95 | 0 |
| `V_U` | 8098.25 | 6937.99 |
| `V_E` | 12268.55 | 10340.00 |
| `a_optimal` | 0.0000 | 0.0070 |

这些结果能支持的结论有：

- 就业者的 `S`、`D`、`W`、`V_U`、`V_E` 均高于失业者。
- 失业者的技能和数字素养显著更弱，这与“长期失业伴随人力资本劣势”这一叙述方向一致。
- 就业者与失业者的长期价值差距仍然明显，说明就业状态仍具有持续收益溢价。

但有两点需要特别注意：

1. 当前导出的 `a_optimal` 已被明确定义为“失业状态下的最优搜索努力”，因此就业者努力应为 `0`，不能再像旧文稿那样同时报告“就业者努力均值”。
2. 失业者的平均努力只有 `0.0070`，中位数为 `0`，说明最优努力整体非常低，不能再写成“均衡时平均努力约 0.1”这一类表述。

### 2.3 努力决策结果

当前结果对第 5.3 节最重要的含义是：

- 失业者努力水平整体极低，且大量个体的最优解落在 `0`。
- 因此，当前版本更像“低努力、低响应”的均衡，而不是“失业者普遍维持中等搜索强度”的均衡。

这意味着第 5.3 节当前可以保留“边际收益递减导致努力下降”这一方向性解释，但不宜再强调：

- “均衡时平均努力约 0.1”
- “高技能个体以略低努力实现匹配”这种较强的横截面行为结论

因为当前导出值显示，大部分失业者已经贴近零努力，群体之间的努力差异并不大。

### 2.4 关于匹配与市场摩擦的补充判断

虽然论文当前已不再把 `M5/M6` 作为正式目标矩，但从场景 baseline 的底层结果看：

- `job_finding_rate ≈ 0.939`
- `separation_rate ≈ 0.039`

这说明当前 `4%` 左右的失业率，很大程度上是由“高找到率 + 高分离率”的高流动率市场内生出来的，而不是一个低流动、低摩擦的稳定市场。因此第 5.4 节如果要讨论匹配效率，当前更适合写成：

- “模型给出的均衡失业率约为 4%，但其内生结构仍表现为较高流动率”

而不宜直接把它解释为“典型农村劳动力市场已被准确刻画”。

## 三、对应论文第六部分的结果说明

### 3.1 宏观政策效果

当前表 6.2 中所有场景都仍是：

- `converged=False`
- `paper_eligible=False`

因此，这一节目前更适合作“诊断性排序”，不适合写成最终政策优先级结论。

如果仅按当前表 6.2 的失业率水平做内部比较，表现较好的几组是：

| 场景 | 失业率 |
| --- | ---: |
| A1 数字素养提升（低） | 3.75% |
| D2 灵活工时（高） | 3.76% |
| C1 就业信息优化（低） | 3.81% |
| B2 职业技能提升（高） | 3.95% |
| E2 失业保障提升（高） | 4.00% |

表现较弱的几组是：

| 场景 | 失业率 |
| --- | ---: |
| C2 就业信息优化（高） | 4.35% |
| A2 数字素养提升（高） | 4.25% |
| E1 失业保障提升（低） | 4.25% |
| D1 灵活工时（低） | 4.15% |

与当前论文文字最不一致的地方主要有三点：

1. 组合政策 `F` 当前不是最优场景，失业率为 `4.10%`，只比基准略低。
2. 数字素养政策呈现“低强度优于高强度”的逆转现象，A1 好于 A2。
3. 信息政策也呈现“低强度优于高强度”的逆转现象，C1 好于 C2。

因此，第 6.2 节当前不能再写“组合政策效果最强、存在明显协同效应”这一强结论。

### 3.2 工资与福利维度

如果看工资与失业者福利：

- 平均工资在各场景之间的变化其实很小，基本都在 `4522` 到 `4541` 之间。
- 失业者福利 `V_U` 提升最明显的仍然是保障类政策：
  - `E2` 相对基准约 `+516.62`
  - `E1` 相对基准约 `+247.51`
- 组合政策 `F` 仅约 `+92.35`

这意味着第 6.2 节当前还能保留的一条结论是：

- 失业保障政策对福利的改善最明显

但关于失业率的作用方向，当前结果并不够稳定，不能写得太满。

### 3.3 分群体政策效果

当前表 6.3 的 baseline 为：

- 高技能失业率：`2.94%`
- 低技能失业率：`5.36%`
- 差距：`2.42pp`

在各政策中：

- 低技能组失业率最低的是 `digital_low = 4.84%`
- 其次是 `flexwork_high = 4.90%`
- 再次是 `info_low = 4.92%`

如果看高低技能差距压缩效果：

- `digital_low` 差距最小，为 `2.18pp`
- `info_low` 为 `2.22pp`
- `flexwork_high` 与 `benefit_high` 均为 `2.28pp`

这与当前论文文字中“D2 对缩小差距最显著”“组合政策最好”并不一致。当前版本更接近的描述应该是：

- 部分低强度政策对低技能群体更友好；
- 但这种优势并不稳定，也未形成统一的组合政策协同格局。

## 四、对应论文第七部分的结果说明

### 4.1 灵敏度分析

当前表 7.1 中，所有 12 组扰动结果仍然都是 `converged=False`。因此这一节仍不能写成严格意义上的“稳健性已被验证”。

当前可以确认的一条较稳的事实是：

- 平均工资对参数扰动非常不敏感，全部变化都在 `1%` 以内，当前最大约为 `-0.67%`。

但失业率的响应方向并不稳定，主要表现为：

- `rho` 的四组扰动结果全部使失业率低于 baseline，其中 `-10%` 和 `-20%` 的降幅反而更大。
- `kappa` 增大时，失业率反而下降得更多，这与“努力成本提高应推高失业率”的标准直觉不一致。
- `alpha_T` 的符号只有 `+20%` 时表现为失业率上升，其余三组都低于 baseline。

因此，第 7.1 节当前最多只能写：

- 工资对参数扰动不敏感；
- 失业率对参数确实有响应；

但不能再写：

- “`rho` 与 `kappa` 的影响方向符合理论预期”
- “核心结论在参数扰动下保持稳健”

### 4.2 数值稳健性与收敛讨论

从当前可获得的最近 100 轮场景 baseline 轨迹看：

- 失业率均值约 `3.968%`，标准差约 `0.172` 个百分点。
- 平均工资均值约 `4522.92`，标准差约 `5.18`。
- `convergence_a` 已较小，最后一轮约 `0.0001`。
- 但 `convergence_V` 最后一轮仍约 `0.131`，`convergence_u` 最后一轮约 `0.0016`。

这意味着：

- 宏观量确实没有大幅乱跳；
- 但值函数层面仍不能说“已充分收敛”。

因此，第 7.2 节更稳妥的口径应是：

- “结果已表现出准稳态特征，但严格收敛条件尚未满足”

而不是：

- “结果具有足够稳健性，可直接支持全部政策与灵敏度结论”

## 五、当前版本最适合保留的结论

若只从当前结果中提炼最稳妥、最不容易被追问击穿的结论，建议保留以下几条：

1. 当前基准均衡失业率约在 `4%` 左右，高于目标 `3.5%`，但量级上已经接近。
2. 就业者在技能、数字素养、保留工资和长期价值上均高于失业者。
3. 失业保障政策对失业者福利提升最明显。
4. 工资水平对参数扰动不太敏感。

## 六、当前版本不建议写强结论的地方

以下结论建议暂时不要作为正文中的强判断：

1. “模型已经收敛”
2. “组合政策效果最强并存在显著协同”
3. “灵活工时或技能政策是最优单一政策”
4. “`rho`、`kappa`、`alpha_T` 的方向都符合理论预期”
5. “灵敏度分析验证了主要结论的稳健性”

## 七、简短结论

这轮结果最大的优点是：论文表格口径已经统一，基准场景和分组表不再混乱。

这轮结果最大的限制是：数值模拟本身仍未真正收敛，且分布矩、政策排序和灵敏度方向都还不够稳定。

因此，当前结果已经适合写成一份“阶段性数值结果说明”，但还不适合直接固化为论文终稿的定量结论。
