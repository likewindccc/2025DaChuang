| 据国家统计局《2024年农民工监测调查报告》显示，2024年全国农民工总量为29973万人，女性占37.6%，比上年提高0.3%。本地农民工中女性占44.2%，外出农民工中女性占31.7%。全部农民工中有配偶的占78.9%，已婚农村女性大多留守。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 近年来，学者围绕农村女性就业困境展开了多维度研究发现，农村女性在劳动力市场中面临家庭照料负担、人力资本不足、社会资本匮乏、数字鸿沟等多重障碍。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 首先，家庭照料被视为农村女性非农就业的重要障碍，包括儿童照管(熊瑞祥，李辉文,2016)和老年照护(于新亮等,2016)，且子女处于不同受教育阶段对农村已婚女性非农就业的影响不同(韩叙等,2019)。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 其次，人力资本与社会资本短板制约农村女性非农就业。木凯代斯·阿布拉(2018)发现，农村女性因教育水平低、职业培训缺乏等，多集中于低端服务业。曹枞(2022)指出，农村女性在劳动权益、生育成本及性别歧视中处于弱势。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 再次，数字时代为农村女性就业带来机遇与挑战。何志扬等(2022)利用CGSS数据发现，互联网使用通过提升社会资本促进农村女性非农就业。许玲丽和陈云菲(2024)进一步揭示数字经济与农村女性就业呈非线性关系：初期提升劳动参与率和收入，但高数字水平对低技能岗位的促进作用减弱，推动女性向高质量服务业转移。                                                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 现有研究指出，利用新兴起的数字技术正可以推动该群体拓宽新就业渠道，解决就业问题。对于劳动力市场中的农村女性，需要为其提供针对性的、多样化、多层次的职业技能培训，提高其数字素养，从而提高就业竞争力(常海晴等,2020)；需要进一步完善农村地区的数字基础设施建设，降低网络使用成本，提供更好的网络创业就业物质环境(范明欣等,2024)；更要减小信息差，提高匹配效率，切实促进农村女性充分就业。                                                                                                                                                                                                                                                                                                             |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 现有研究多是只关注农村女性这一劳动力市场群体，少有同步关注到提供岗位的企业、以及在调配供需过程中起到重要作用的平台，更少有研究能以一体化的宏观视角分析劳动力就业的匹配过程，试图寻求最优解，从而减小两边信息差，以达到充分就业这种劳动力市场的"帕累托最优"。                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 在分析包含大量异质性主体互动的复杂经济系统时，基于主体建模(Agent Based Modeling, ABM)与平均场博弈(Mean Field Game, MFG)理论提供了两种研究路径，二者在劳动经济学等领域均有应用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 基于主体建模是一种计算模拟方法,其核心特征在于模拟具有异质性和有限理性的主体行为。Tesfatsion(2001)构建了一个演化劳动力市场，Neugart & Richiardi(2018)提出，ABM常用于复现劳动力市场的典型化事实和进行政策评估。Goudet et al.(2017)开发的WorkSim模型模拟了法国劳动力市场中不同合同类型下，采用无匹配函数的双边搜索与有限理性决策进行政策实验。                                                                                                                                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 平均场博弈则源于Lasry&Lions(2007)的开创性工作，它研究由大量理性参与者组成的系统。在劳动经济学中，Perthame et al.(2018)应用MFG分析了个体最优职业规划与市场工资结构间的关系。Gao et al.(2025)则将MFG框架扩展至动态双边匹配市场，用于捕捉劳动力市场中两个不同群体（如工人和企业）的同时互动。                                                                                                                                                                                                                                                                                                                                                                                                         |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Copula方法是模拟相依结构的重要工具。其理论核心基于Sklar(1959)定理。李健伦等(2005)总结了该方法在金融经济学中的应用，特别是研究多债务人的相依违约问题。Aas et al.(2006)提出基于对偶Copula构造或Vines的层级建模方法。此方法将高维密度分解为一系列二级Copula的级联。Nikoloulopoulos(2013)在其综述中指出，该技术也高效地应用于多元离散响应数据。Panagiotelis et al.(2012)的方法允许将联合概率质量函数递归分解，避免了传统椭圆Copula（如多元正态模型）所需的高维积分问题。                                                                                                                                                                                                                               |

| 平均场博弈是一种基于大量异质性个体的博弈系统，因此我们需要生成大量虚拟个体以模拟现实的劳动力市场。为利用有限样本构建总体分布且解决个体不同特征之间的相关性问题，我们先基于样本拟合出劳动力的劳动时间、需求薪资、技能水平、数字素养等特征的最佳边际分布，再利用Sklar于1959年提出的Copula函数将多个单一维度的边际分布进行联结，得到一个多元正态分布$N(0,\Sigma)$，每一个劳动力都可以用该分布上的一个点来表示。因此我们可以从$N(0,\Sigma)$上采样$N$个劳动力个体，并假设企业端对劳动时间、技能水平、数字素养水平的需求以及可供给薪资也服从与多元正态分布，根据市场紧张度$\theta$采样生成对应数量的企业数量，进而得到一个大规模的、足够贴近现实的虚拟农村女性劳动力市场。                               |

| 显然，不同劳动力由于其个体特征的异质性，在就业市场上的求职成功率也存在着较大差异。根据访谈结果，我们可以发现，对于当下农村女性劳动力而言，工作时间、工作技能水平、数字素养水平与工作薪酬这四个要素是影响求职成功率的最重要原因，因此我们可以构建"就业匹配概率-劳动力个体特征"匹配概率函数来刻画每个劳动力个体在求职过程中的成功概率。                                                                                                                                                                                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 为获得自然条件下的市场匹配结果，我们假设劳动力的求职过程是一个与企业进行双向选择的匹配过程，引入了Gale-Shapley匹配算法，从总体分布中抽样大量劳动力个体与企业岗位，并进行多批次（每批次1000个劳动力个体）有限轮次的GS算法双向选择匹配，得到100000条劳动力的匹配数据，并进一步基于匹配数据进行Logistic回归得到劳动力匹配概率函数：                                                                                                                                                                                                                                                                                                                                                                   |

| 平均场博弈框架主要由两个方程：贝尔曼方程(Bellman Equation)与柯尔莫哥洛夫前向方程(Kolmogorov Forward Equation, KFE)构成。贝尔曼方程主要用于刻画个体在给定市场状态下的最优努力行为，柯尔莫哥洛夫前向方程（下文均用KFE指代）用于描述个体决策汇聚后市场状态随时间的演化。                                                                                                                                                                                                                                                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 本研究中具体的贝尔曼方程形式如下：                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| $$V_{t}^{U}\left( x,\sigma_{i} \right) = \max_{a_{t} \in \lbrack 0,1\rbrack}\left\{ \left\lbrack b(x) - \frac{1}{2}\kappa a_{t}^{2} \right\rbrack + \rho\left\lbrack \lambda\left( x_{t},\sigma_{i},\theta_{t} \right)V_{t + 1}^{E}\left( x_{t + 1},\sigma_{i} \right) + \left( 1 - \lambda\left( x_{t},\sigma_{i},\theta_{t} \right) \right)V_{t + 1}^{U}\left( x_{t + 1},\sigma_{i} \right) \right\rbrack \right\}$$                                                                                                                                                                                                                                                                             |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| $$V_{t}^{E}\left( x,\sigma_{i} \right) = \omega\left( x_{t},\sigma_{i} \right) + \rho\left\lbrack \mu\left( x_{t},\sigma_{i} \right)V_{t + 1}^{U}\left( x_{t + 1},\sigma_{i} \right) + \left( 1 - \mu\left( x_{t},\sigma_{i} \right) \right)V_{t + 1}^{E}\left( x_{t + 1},\sigma_{i} \right) \right\rbrack$$                                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 具体的KFE形式如下：                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| $$m^{U}\left( x_{t + 1},t + 1 \right) = \sum_{x}^{}{\lbrack(1 -}\lambda\left( x_{t},\sigma_{i},\theta_{t} \right)) \cdot I\left( x_{t + 1} \middle| x_{t},a^{*}\left( x_{t},t \right) \right) \cdot m^{U}(x_{t},t)\rbrack$$                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| $$+ \mu\left( x_{t},\sigma_{i} \right) \cdot m^{E}\left( x_{t},t \right)$$                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| $$m^{E}\left( x_{t + 1},t + 1 \right) = \sum_{x}^{}{\lbrack\lambda\left( x_{t},\sigma_{i},\theta_{t} \right)) \cdot I\left( x_{t + 1} \middle| x_{t},a^{*}\left( x_{t},t \right) \right) \cdot m^{U}(x_{t},t)\rbrack}$$                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| $$+ \left( 1 - \mu\left( x_{t},\sigma_{i} \right) \right) \cdot m^{E}\left( x_{t},t \right)$$                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

| 三、未来工作安排                                                                                                                                                                                                                                                                                                                                                                                                 |                                                                                                                                  |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------+
| 目前项目已经进行了两轮问卷调查以及个例访谈，并基本完成了中国农村女性劳动力市场的仿真模拟系统的开发以及项目网站以及应用程序的构建。但仍存在如下问题尚未解决：                                                                                                                                                                                                                                                     |                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                                                                  |                                                                                                                                  |
| 1.仿真系统内各类模型的参数未达最优：由于劳动力个体的决策涉及大量主观因素，因此模型的主观参数众多，且难以通过问卷有效测度或是借鉴现有研究来确定。模型是否很好地贴合了现实情况或是真实地反映了劳动力市场在个体主观决策下的演化仍有待明确，如何证明系统的稳态结果与现实中的情况一致或类似也是一个重要问题。                                                                                                         |                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                                                                  |                                                                                                                                  |
| 2.由于系统构建的复杂程度，导致目前系统的易用性以及普及度难以提升，初版的应用程序尚处在早期开发阶段，仍存在大量需要优化的部分。                                                                                                                                                                                                                                                                                   |                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                                                                  |                                                                                                                                  |
| 3.仿真系统模拟出的结果仅仅只是一组数据和图表，如何通过这些数据与图表，探索出中国农村女性劳动力市场的演化规律以及在不同政策下的反应，并将模型结果落实到实际实践过程中，也是另一大关键问题。                                                                                                                                                                                                                       |                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                                                                  |                                                                                                                                  |
| 针对上述提到的三个问题，我们团队确定了三点在未来阶段的主要工作来对应解决这些问题：                                                                                                                                                                                                                                                                                                                               |                                                                                                                                  |
