📸 如何导出高分辨率PNG图片

  1. Chrome浏览器（推荐）：
    • 按 F12 打开开发者工具
    • 按 Ctrl+Shift+P 打开命令面板
    • 输入 screenshot 并选择 Capture node screenshot
    • 点击选择下方的流程图SVG元素
    • 图片将自动下载为PNG（原始分辨率）
  2. 或者直接右键：
    • 在流程图上右键点击
    • 选择"另存为图片"或"Save image as"
    • 保存为PNG格式
  3. 一键复制到剪贴板：
    • 点击下方的"复制流程图"按钮
    • 然后可以直接粘贴到Word、PowerPoint等应用中
