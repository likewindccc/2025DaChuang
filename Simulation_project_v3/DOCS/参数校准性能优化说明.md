# 参数校准性能优化说明

## 文档定位

本文档说明本次针对参数校准与 MFG 求解链路的性能优化改动，覆盖以下模块：

- `MODULES/CALIBRATION/smm_calibrator.py`
- `MODULES/MFG/equilibrium_solver.py`
- `MODULES/MFG/bellman_solver.py`
- `MODULES/MFG/kfe_solver.py`
- `CONFIG/calibration_config.yaml`

## 上下游关系

### 上游依赖

- `CONFIG/mfg_config.yaml`：提供 MFG 求解参数。
- `CONFIG/calibration_config.yaml`：提供校准阶段与优化器配置。
- `MODULES/POPULATION/labor_distribution.py`：提供基础人口分布拟合与采样能力。
- `OUTPUT/logistic/match_function_model.pkl`：提供匹配概率预测模型。

### 下游使用方

- `run_calibration.py`：触发完整的 SMM 校准流程。
- `MODULES/CALIBRATION/objective_function.py`：通过 `mfg_solver` 间接调用均衡求解。
- `GUI/workers/simulation_worker.py` 等界面或脚本入口：复用校准与均衡求解结果。

## 本次优化目标

本次优化重点解决以下问题：

- 校准过程中每次目标函数评估都重复拟合并采样人口，固定成本过高。
- Bellman 求解每轮外层迭代都从零值函数开始，未利用上一轮结果。
- 匹配概率计算大量依赖 `iterrows()` 和 `predict(DataFrame)`，Python 层开销明显。
- `Stage 5` 协方差阶段当前退化，继续启用会增加耗时且可能恶化结果。

## 关键改动

### 1. 基础人口样本复用

文件：`MODULES/MFG/equilibrium_solver.py`、`MODULES/CALIBRATION/smm_calibrator.py`

改动说明：

- 在 `EquilibriumSolver` 中新增 `create_base_population_sample()`。
- 该方法只生成基础状态样本和 `initial_T`，不写入就业状态与当前工资。
- `initialize_population()` 支持接收外部传入的 `base_population` 与 `initial_T`。
- `SMMCalibrator` 在一次校准开始时只生成一份基础人口样本，随后所有参数点评估复用同一份样本。

这样做的收益：

- 避免每次评估都重复 `fit + sample` 人口分布。
- 保持不同参数点评估使用同一基础样本，减少目标函数的额外抽样噪声。

实现约束：

- 每次初始化时都会对基础样本执行 `copy(deep=True)`，避免跨参数点评估互相污染。
- `initial_T` 与基础样本绑定复用，保证 `disutility_T` 计算口径一致。

### 2. Bellman warm start

文件：`MODULES/MFG/bellman_solver.py`、`MODULES/MFG/equilibrium_solver.py`

改动说明：

- `value_iteration_unified_numba()` 新增 `initial_V_U`、`initial_V_E` 输入。
- `BellmanSolver.solve()` 支持外部传入上一轮值函数作为初值。
- `EquilibriumSolver.solve()` 将上一轮外层迭代的 `prev_V_U`、`prev_V_E` 直接喂回下一轮 Bellman 求解。

这样做的收益：

- 降低每轮外层迭代中的 Bellman 值迭代轮数。
- 在均衡已经接近收敛时，通常能显著缩短内层求解时间。

### 3. 匹配概率矩阵化预测

文件：`MODULES/MFG/bellman_solver.py`、`MODULES/MFG/kfe_solver.py`

改动说明：

- 缓存匹配模型参数与列顺序。
- 使用 `design_matrix @ coef -> sigmoid` 替代逐行 `predict(DataFrame)`。
- `BellmanSolver.compute_match_probabilities_batch()` 改为一次性广播生成 `(N, n_effort)` 的预测输入。
- `KFESolver.compute_match_probabilities()` 改为一次性向量化生成最优努力对应的匹配概率。
- `KFESolver.compute_separation_rates()` 也改为 NumPy 向量化。

这样做的收益：

- 显著减少 `iterrows()`、DataFrame 构造和 statsmodels 包装层开销。
- Bellman 和 KFE 两条热点链路都能吃到向量化收益。

验收重点：

- 预测列顺序必须与模型训练时的 `exog_names` 保持一致。
- 若模型包含未支持列，代码会显式抛错，避免静默算错。

### 4. 关闭 Stage 5

文件：`CONFIG/calibration_config.yaml`

改动说明：

- 将 `two_stage_calibration.stage5.enabled` 改为 `false`。

原因：

- 当前协方差估计阶段缺少有效的独立随机扰动，容易退化为无效协方差矩阵。
- 在该问题彻底修复前，继续启用会带来额外耗时和不稳定性。

## 典型调用链

### 校准阶段

1. `SMMCalibrator.calibrate()`
2. `_create_base_population_sample()`
3. `_create_mfg_solver(base_population, base_initial_T)`
4. `solve_equilibrium(..., base_population=..., initial_T=..., verbose=False)`
5. `EquilibriumSolver.initialize_population()`
6. `BellmanSolver.solve()` 与 `KFESolver.evolve()` 交替迭代

### 单次均衡求解

1. 复用基础人口样本并初始化就业状态。
2. Bellman 批量计算匹配概率并执行值迭代。
3. KFE 基于最优努力向量化更新匹配率和离职率。
4. 外层迭代使用上一轮值函数做 warm start。

## 输入输出示例

### 输入

- `base_population`：包含 `T/S/D/W/age/education/children` 的 `DataFrame`
- `initial_T`：与个体顺序一一对应的 `np.ndarray`
- `params_vector`：校准器传入的待评估参数向量

### 输出

- `EquilibriumSolver.solve()`：
  - `individuals_equilibrium`
  - `equilibrium_info`
- `SMMCalibrator._create_mfg_solver()`：
  - `(individuals, eq_info)`，供目标矩计算使用

## 验收与测试建议

本次改动后的建议验收口径：

- 代码能通过 `py_compile`。
- 小样本烟雾测试能跑通基础样本生成、初始化、Bellman、KFE 演化。
- 同一基础样本下，目标函数计算过程不应因对象原地污染而异常漂移。
- 若后续恢复 `Stage 5`，必须先重新设计独立随机扰动与协方差估计方案。
