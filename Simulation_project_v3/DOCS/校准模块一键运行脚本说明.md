# 校准模块一键运行脚本说明

## 1. 文件位置

- 运行脚本：`Simulation_project_v3/run_calibration.py`
- 核心调用：`MODULES.CALIBRATION.SMMCalibrator.calibrate()`

该脚本是对当前校准实现的命令行封装，目的是提供统一、可复用的一键入口。

---

## 2. 基本用法

在项目根目录下执行：

```bash
cd D:\Python\2025DaChuang\Simulation_project_v3
python run_calibration.py
```

默认行为：

1. 读取 `CONFIG/calibration_config.yaml`；
2. 使用配置中的 `optimization.method`；
3. 启用 `allow_auto_resume=True`（可自动从最新断点恢复）；
4. 运行结束后打印 `success/fun/nfev` 以及关键输出文件检查结果。

---

## 3. 常用参数

```bash
python run_calibration.py --help
```

常用参数如下：

- `--config`：指定校准配置文件路径。
- `--method`：覆盖优化方法（例如 `differential_evolution`、`Powell`）。
- `--initial-strategy`：初始值策略（`baseline/random/midpoint/sensitivity`）。
- `--initial-values`：手工传入初始参数向量（逗号分隔）。
- `--no-auto-resume`：禁用自动断点恢复。
- `--log-level`：日志级别（默认 `INFO`）。

---

## 4. 示例命令

### 4.1 正式运行（推荐）

```bash
python run_calibration.py
```

### 4.2 禁用自动续跑，从当前配置重新开始

```bash
python run_calibration.py --no-auto-resume
```

### 4.3 临时覆盖优化方法

```bash
python run_calibration.py --method Powell --no-auto-resume
```

### 4.4 手工指定初始值

```bash
python run_calibration.py --initial-values "0.4,1500,0.25,0.3,0.35,0.45,0.15"
```

---

## 5. 输出结果检查

脚本结束后会检查以下关键文件是否存在（目录：`OUTPUT/calibration`）：

1. `calibration_stage_summary.yaml`
2. `calibrated_parameters.yaml`
3. `optimization_result.pkl`

若正式校准成功，以上文件应全部存在。

## 6. 日志行为说明

自 2026-03-18 起，校准链路中的目标函数评估摘要与目标矩对比信息统一改为 `logging` 输出，不再依赖 `print` 向标准输出直接刷屏。这样做有三点好处：

1. 与 `run_calibration.py` 的日志级别控制保持一致；
2. 服务器端运行时可以直接写入统一日志，不会把评估细节散落到非结构化输出中；
3. 后续若需要重定向到文件、采集器或调度平台，不需要再额外包裹 stdout。

因此，当前推荐的观察方式是直接查看 `run_calibration.py` 的日志输出，而不是依赖历史版本中的控制台打印。
