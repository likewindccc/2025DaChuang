## 1. 项目总体架构

### 1.1 项目定位与研究目标

本项目是基于**平均场博弈（Mean Field Game, MFG）**与**基于主体建模（Agent-Based Model, ABM）**思想的农村女性就业市场动态模拟系统。

**核心研究问题**：

1. 农村女性如何动态调整努力水平以提高就业机会？
2. 个体决策与宏观市场状态如何相互作用？
3. 如何设计最优政策组合促进农村女性就业？

### 1.2 理论基础

**平均场博弈（MFG）框架**：

- 适用于大规模主体博弈问题（N → ∞）
- 个体决策依赖于宏观分布而非其他个体的具体策略
- 通过Bellman方程求解个体最优策略
- 通过Kolmogorov前向方程（KFE）求解人口分布演化

**关键特征**：

- **异质性主体**：劳动力具有不同的技能（T, S, D, W）和背景特征（age, edu, children）
- **状态空间**：4维连续状态空间（T：工作时长，S：技能水平，D：数字素养，W：期望工资）
- **动态演化**：通过努力水平a影响状态转移和匹配概率
- **市场机制**：双边匹配市场（劳动力-企业），通过Gale-Shapley算法实现

### 1.3 系统架构设计

项目采用**模块化、分层设计**，遵循自底向上的依赖关系：

```text
CALIBRATION (参数校准层) - 第5层
    ↓ 调用
SIMULATOR (模拟分析层) - 第4层
    ↓ 调用
MFG (平均场博弈层) - 第3层
    ↓ 调用
LOGISTIC (匹配函数层) - 第2层
    ↓ 调用
POPULATION (人口分布层) - 第1层（基础层）
```

**设计原则**：

- **单向依赖**：高层依赖低层，低层不依赖高层
- **模块独立**：每个模块可独立测试和运行
- **职责清晰**：每个模块有明确的输入、输出和职责边界
- **配置驱动**：通过YAML配置文件管理参数，代码与配置分离

## 2. POPULATION模块分析

### 2.1 模块职责

**核心功能**：从预处理的真实数据中建立劳动力和企业的**概率分布模型**，为后续模块提供采样基础。

**重要说明**：该模块**不生成具体个体**，只建立分布的**参数模型**。

### 2.2 技术架构

#### 2.2.1 劳动力分布建模（`labor_distribution.py`）

**挑战**：劳动力特征包含**连续变量**和**离散变量**，且存在复杂的相关性。

**解决方案**：分治策略

1. **连续变量**（T, S, D, W, age）：使用**Gaussian Copula**建模
   - Copula理论：分离边际分布和依赖结构
   - 边际分布：由数据拟合（经验分布或核密度估计）
   - 依赖结构：通过协方差矩阵捕捉相关性

2. **离散变量**（edu, children）：记录**经验分布**（频率分布）
   - 直接统计每个取值的出现频率
   - 采样时按频率进行离散抽样

**实现流程**：
```python
class LaborDistribution:
    def fit(self):
        # 1. 加载预处理数据
        data = self._load_data()
        
        # 2. 拟合连续变量的Copula
        continuous_vars = ['T', 'S', 'D', 'W', 'age']
        self.copula_model = GaussianMultivariate()
        self.copula_model.fit(data[continuous_vars])
        
        # 3. 记录离散变量的经验分布
        self.discrete_dist = {
            'edu': data['edu'].value_counts(normalize=True).to_dict(),
            'children': data['children'].value_counts(normalize=True).to_dict()
        }
    
    def save_params(self):
        # 保存Copula模型对象和离散分布参数
        params = {
            'copula_model': self.copula_model,
            'discrete_dist': self.discrete_dist
        }
        pickle.dump(params, filepath)
```

**数据转换**：

- **T（工作时长）**：`T = 每周工作天数 × 每天工作小时数`
- **S（技能水平）**：从原始问卷分数映射
- **D（数字素养）**：从原始问卷分数映射
- **W（期望工资）**：从原始收入数据提取

#### 2.2.2 企业分布建模

**数据来源**：由于缺乏企业端真实数据，企业分布参数来自**文献估计**和**初始设定**。

**分布假设**：4维多元正态分布

```yaml
企业特征:
  T_req: 工作时长要求
  S_req: 技能要求
  D_req: 数字化要求
  W_offer: 提供薪资

参数:
  mean: [均值向量]
  std: [标准差向量]
  correlation: [相关系数矩阵]
```

企业参数在`population_config.yaml`中配置，后续通过**CALIBRATION模块**校准调整。

### 2.3 输出产物

**保存文件**：`OUTPUT/population/labor_distribution_params.pkl`

**内容**：

- `copula_model`：训练好的GaussianMultivariate对象
- `discrete_dist`：离散变量的频率字典

**后续使用**：LOGISTIC模块和MFG模块通过加载该文件进行采样。

#### 3.2.2 GS匹配算法（`gs_matching.py`）

**算法**：Gale-Shapley稳定匹配算法

**改进**：引入**有限轮次**机制模拟真实市场摩擦

**偏好函数设计**：

**劳动力偏好企业**：

```text
u_L(i, j) = γ_0 - γ_1·T_req - γ_2·max(0, S_req - S_i) 
            - γ_3·max(0, D_req - D_i) + γ_4·W_offer
```

- 偏好低时长要求、低技能要求、高薪资的岗位
- 如果企业要求超过自身能力，产生负效用

**企业偏好劳动力**：

```text
u_E(j, i) = β_0 + β_1·T_i + β_2·S_i + β_3·D_i + β_4·W_i
```

- 偏好高工作时长、高技能、高数字素养、低期望工资的劳动力

**关键技术**：

1. **MinMax标准化**：对每一项分别标准化到[0,1]，确保各维度贡献均衡
2. **Numba加速**：偏好计算使用`@njit`装饰器，实现3-5倍加速
3. **有限轮次匹配**：`max_rounds=32`（经调优），模拟信息不对称和搜寻成本

## 4. MFG模块分析

### 4.1 模块职责

**核心任务**：求解平均场博弈均衡，即找到个体最优策略和宏观人口分布的不动点。

**理论基础**：
- **Bellman方程**：求解个体最优决策
- **KFE（Kolmogorov前向方程）**：求解人口分布演化
- **均衡条件**：策略与分布相互自洽

### 4.2 模块架构

MFG模块包含3个核心求解器：

#### 4.2.1 Bellman求解器（`bellman_solver.py`）

**理论公式**（研究计划4.1.1节）：

**失业者价值函数**：

```text
V^U(x) = max_a {u(a) + ρ·[λ(x,a,θ)·V^E(x') + (1-λ)·V^U(x')]}
```

**就业者价值函数**：

```text
V^E(x) = w(x) + ρ·[μ(x)·V^U(x) + (1-μ)·V^E(x)]
```

其中：

- `u(a) = b - 0.5·κ·a² - α_T·(T-T_0)²`：失业者即时效用
- `w(x)`：就业者工资收入
- `λ(x,a,θ)`：匹配概率（从LOGISTIC模块）
- `μ(x,σ)`：外生离职率（Logistic函数）
- `x'`：下期状态（通过努力a更新）

**状态更新方程**：

```python
T' = T + γ_T · a · (T_max - T)
S' = S + γ_S · a · (1 - S_norm)  # MinMax标准化后更新
D' = D + γ_D · a · (1 - D_norm)
W' = max(W_min, W - γ_W · a)
```

**实现策略**：统一处理所有个体

**关键创新**：不区分失业/就业，同时计算V_U和V_E

```python
@njit(parallel=True)
def solve_bellman_unified_numba(...):
    for i in prange(N):  # 并行循环
        # 1. 计算V_U[i]（失业状态价值）
        for a in a_grid:
            # 即时效用
            instant_utility = b - 0.5·κ·a² - α_T·(T-T_0)²
            
            # 下期期望价值
            V_next = λ·V_E_next[i] + (1-λ)·V_U_next[i]
            
            # 总价值
            total_value = instant_utility + ρ·V_next
        
        V_U[i] = max(total_value)
        a_optimal[i] = argmax(...)
        
        # 2. 计算V_E[i]（就业状态价值）
        instant_utility = current_wage[i] - α_T·(T-T_0)²
        V_next = μ·V_U_next[i] + (1-μ)·V_E_next[i]
        V_E[i] = instant_utility + ρ·V_next
    
    return V_U, V_E, a_optimal
```

- Numba并行加速（`parallel=True`）：10-30倍加速

- 相对收敛标准：更稳定

#### 4.2.2 KFE求解器（`kfe_solver.py`）

**理论公式**（研究计划4.1.2节）：

**失业者分布演化**：

```text
m^U(x_{t+1}) = Σ[(1-λ)·I(x'|x,a*)·m^U(x_t)] + μ·m^E(x_t)
```

**就业者分布演化**：

```text
m^E(x_{t+1}) = Σ[λ·I(x'|x,a*)·m^U(x_t)] + (1-μ)·m^E(x_t)
```

**实现方法**：**基于个体的蒙特卡洛模拟**

**为什么不用网格法**？

- 4维状态空间离散化需要10^8个网格点（维度灾难）
- 蒙特卡洛方法：模拟N=10,000个具体个体
- 大数定律保证：经验分布收敛到理论密度函数

**实现流程**：
```python
@njit(parallel=True)
def simulate_population_evolution(...):
    for i in prange(N):  # 并行循环每个个体
        # 1. 更新就业状态
        if is_unemployed[i]:
            # 以概率λ匹配成功
            if random() < lambda_probs[i]:
                employment_status_new[i] = False  # 转为就业
            else:
                employment_status_new[i] = True   # 保持失业
        else:
            # 以概率μ离职
            if random() < mu_probs[i]:
                employment_status_new[i] = True   # 转为失业
            else:
                employment_status_new[i] = False  # 保持就业
        
        # 2. 更新状态变量（使用最优努力a*）
        if is_unemployed[i]:
            a_opt = optimal_effort[i]
            T_new[i] = T[i] + γ_T·a_opt·(T_max - T[i])
            # ... 其他状态更新
        else:
            # 就业者状态不变
            T_new[i] = T[i]
        
        # 3. 更新工资
        if 新匹配成功:
            current_wage_new[i] = W_new[i]  # 就业收入 = 期望工资
        elif 保持就业:
            current_wage_new[i] = current_wage[i]  # 工资不变
        else:
            current_wage_new[i] = 0  # 失业无收入
    
    return employment_status_new, T_new, S_new, D_new, W_new, current_wage_new
```

**收敛标准**（三个条件同时满足）：

1. **价值函数相对变化**：
   ```text
   |ΔV_U| / |V_U| < ε_V (0.01 = 1%)
   |ΔV_E| / |V_E| < ε_V
   ```

2. **平均努力水平变化**：
   ```text
   |mean(a_{t+1}) - mean(a_t)| < ε_a (0.01)
   ```

3. **失业率变化**：
   ```text
   |u_{t+1} - u_t| < ε_u (0.001 = 0.1个百分点)
   ```

**优化技术**：

1. **降低贴现因子**：ρ=0.85（原0.95），加快收敛
2. **阻尼更新**：`individuals_new = 0.5·individuals + 0.5·individuals_new`
3. **相对收敛阈值**：避免绝对值过大导致的不收敛
4. **Numba并行**：Bellman和KFE的核心循环全部并行化

## 6. CALIBRATION模块分析

### 6.1 模块职责

**核心任务**：使用**模拟矩匹配（Simulated Method of Moments, SMM）**方法校准模型的结构参数，使模拟结果与真实数据匹配。

**校准目标**：最小化模拟矩与目标矩之间的加权距离。

### 6.2 理论基础

**SMM目标函数**：
```text
J(Θ) = [m_sim(Θ) - m_data]' · W · [m_sim(Θ) - m_data]
```

其中：

- `Θ`：待校准参数向量
- `m_sim(Θ)`：模拟矩（运行MFG得到）
- `m_data`：目标矩（从真实数据或文献中获取）
- `W`：权重矩阵

**优化算法**：

1. **差分进化（Differential Evolution）**：全局搜索，适合非凸优化
2. **Nelder-Mead**：局部精细化

### 6.3 模块架构

#### 6.3.2 目标函数（`objective_function.py`）

**实现**：
```python
class ObjectiveFunction:
    def __init__(self, target_moments, weight_matrix, mfg_solver):
        self.target_moments = target_moments
        self.W = weight_matrix
        self.mfg_solver = mfg_solver
    
    def __call__(self, params_vector):
        # 1. 运行MFG求解（使用当前参数）
        individuals, eq_info = self.mfg_solver(params_vector)
        
        # 2. 计算模拟矩
        m_sim = self.compute_simulated_moments(individuals, eq_info)
        
        # 3. 计算目标函数值
        m_data = self.target_moments.get_vector()
        residual = m_sim - m_data
        
        J = residual.T @ self.W @ residual
        
        return J
    
    def compute_simulated_moments(self, individuals, eq_info):
        """从MFG均衡结果中提取矩"""
        is_employed = (individuals['employment_status'] == 'employed')
        
        moments = {
            'unemployment_rate': (~is_employed).mean(),
            'mean_wage_employed': individuals.loc[is_employed, 'current_wage'].mean(),
            'std_wage_employed': individuals.loc[is_employed, 'current_wage'].std(),
            'mean_T_employed': individuals.loc[is_employed, 'T'].mean(),
            ...
        }
        
        return np.array(list(moments.values()))
```

#### 6.3.3 SMM校准器（`smm_calibrator.py`）

**实现流程**：
```python
class SMMCalibrator:
    def calibrate(self, use_global_search=True):
        # 1. 定义参数边界
        param_bounds = self.param_utils.get_bounds()
        
        # 2. 定义MFG求解器包装函数
        def mfg_solver(params_vector):
            # 更新配置文件
            update_mfg_config(params_vector)
            # 运行MFG
            return solve_equilibrium()
        
        # 3. 创建目标函数
        obj_func = ObjectiveFunction(
            target_moments=self.target_moments,
            weight_matrix=self.W,
            mfg_solver=mfg_solver
        )
        
        # 4. 全局搜索（差分进化）
        if use_global_search:
            result = differential_evolution(
                func=obj_func,
                bounds=param_bounds,
                maxiter=100,
                workers=4  # 并行
            )
            params_init = result.x
        else:
            params_init = self.param_utils.get_initial_guess()
        
        # 5. 局部精细化（Nelder-Mead）
        result = minimize(
            fun=obj_func,
            x0=params_init,
            method='Nelder-Mead',
            options={'maxiter': 200}
        )
        
        # 6. 保存结果
        self.save_results(result)
        
        return result
```

## 附录：关键公式汇总

### A.1 匹配函数
```text
λ(x,σ,θ) = logistic(α_0 + α_T·T + α_S·S + α_D·D + α_W·W + α_σ·σ + α_θ·θ)
```

### A.2 离职率
```text
μ(x,σ) = logistic(η_0 + η_T·T + η_S·S + η_D·D + η_W·W + η_age·age + η_edu·edu + η_children·children)
```

### A.3 状态更新
```text
T' = T + γ_T·a·(T_max - T)
S' = S + γ_S·a·(1 - S_norm)
D' = D + γ_D·a·(1 - D_norm)
W' = max(W_min, W - γ_W·a)
```

### A.4 Bellman方程
```text
V^U(x) = max_a {b - 0.5·κ·a² - α_T·(T-T_0)² + ρ·[λ·V^E(x') + (1-λ)·V^U(x')]}
V^E(x) = w(x) - α_T·(T-T_0)² + ρ·[μ·V^U(x) + (1-μ)·V^E(x)]
```

### A.5 SMM目标函数
```text
J(Θ) = [m_sim(Θ) - m_data]' · W · [m_sim(Θ) - m_data]
```
