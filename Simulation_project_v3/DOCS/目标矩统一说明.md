# 目标矩统一说明

## 1. 目的

本说明用于明确项目当前“目标矩”的唯一工作口径，避免出现：

- `run_paper_simulation.py` 导表使用一套矩；
- `calibration_config.yaml` 校准时使用另一套矩；
- `mfg_config.yaml` 内部结构目标率又使用第三套矩。

从本次更新开始，项目统一按论文脚本所认定的
`M1/M2/M3/M4/M7/M8` 六个活跃目标矩工作。

---

## 2. 当前统一口径

### 2.1 论文导表口径

`run_paper_simulation.py` 现在显式定义了：

```python
PAPER_TARGET_MOMENT_NAMES = [
    "unemployment_rate",
    "mean_wage",
    "log_std_wage",
    "mean_weekly_hours",
    "wage_iqr_ratio",
    "std_weekly_hours",
]
```

对应 `M1/M2/M3/M4/M7/M8`。

### 2.2 数值取值来源

所有目标值均从 `CONFIG/target_moments.yaml` 读取：

- M1: `0.035`
- M2: `3578.3`
- M3: `0.649`
- M4: `52.0`
- M7: `3.0`
- M8: `16.7`

同时，`CONFIG/target_moments.yaml` 现在显式写明：

- `current_active_moments` 为当前正式口径的 6 个矩；
- 各矩新增 `active_for_current_calibration` 标记；
- `M5/M6` 明确标记为 `false`，仅作历史参考。

### 2.3 校准口径

`CONFIG/calibration_config.yaml` 当前同样只启用
`M1/M2/M3/M4/M7/M8` 六个活跃矩。
`M5/M6` 仍保留在 `CONFIG/target_moments.yaml` 中，仅作历史参考，
不进入当前校准与论文主表。

## 3. 受影响文件

- `run_paper_simulation.py`
  - 显式声明论文使用的目标矩集合。
- `CONFIG/calibration_config.yaml`
  - 当前仅启用 6 个活跃目标矩。
- `CONFIG/target_moments.yaml`
  - 继续作为目标值与元数据的单一来源，保留 `M5/M6` 的历史定义。
- `TESTS/test_calibration_active_moments.py`
  - 更新为校验 6 个激活矩。
- `TESTS/test_target_moments_clds.py`
  - 修正旧的 `std_wage` 名称，统一改为 `log_std_wage`。

---

## 4. 设计说明

### 4.1 为什么再次裁掉 M5/M6

当前要求已经调整，`run_paper_simulation.py` 的主表口径也明确只保留
`M1/M2/M3/M4/M7/M8`。
因此 `M5/M6` 不再作为当前论文主表与校准主目标的一部分。

### 4.2 当前如何处理 `M5/M6`

当前做法是：

- `target_moments.yaml` 里仍保留 `M5/M6` 的历史定义；
- `run_paper_simulation.py` 不再把它们纳入论文表4.4；
- `calibration_config.yaml` 不再把它们纳入当前优化目标；
- `mfg_config.yaml` 默认关闭与 `M5/M6` 对齐的自动结构校准开关。
